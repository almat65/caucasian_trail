# Воспроизведение трека — руководство пользователя

Это приложение показывает GPS-трек, который постепенно рисуется на карте как повтор маршрута (replay), а также точки интереса (POI), которые появляются по мере прохождения трека.

## 1. Подготовка файла трека

### Шаг 1 — Упростите трек с помощью Mapshaper

- Перейдите на сайт: https://mapshaper.org/
- Перетащите исходный файл трека `.geojson` на страницу.
- В панели упрощения выберите **Visvalingam / weighted area**.
- Установите значение упрощения на **1%**.
- Нажмите **Export** и скачайте упрощённый файл.

### Шаг 2 — Проверьте плотность точек

Рекомендуется иметь около **100 точек на каждые 10 км маршрута**.

### Шаг 3 — Поместите файл в проект

Переименуйте файл в `track.geojson` и поместите его в:

```text
json/track.geojson
```

## 2. Редактирование точек интереса (POI)

Откройте файл:

```text
json/POI.geojson
```

Изменяйте координаты, эмодзи и подписи по необходимости.

## 3. Настройка скорости воспроизведения

В файле `app.js`:

```javascript
export const speed = {
  minDurationS: 5,
  maxDurationS: 35,
};
```

## 4. Настройка внешнего вида

### Линии трека

Настраиваются в `player.js` через параметры `color`, `weight` и `opacity`.

### Маркер текущего положения

Настраивается через параметры `radius`, `color` и `fillColor`.

### Маркеры POI и подписи

Настраиваются в `style.css` через `font-size`, `color` и другие CSS-параметры.

## 5. Запуск приложения

### VS Code + Live Server

1. Установите VS Code.
2. Установите расширение Live Server.
3. Откройте папку проекта.
4. Выберите `index.html` → **Open with Live Server**.

### Node.js

```bash
npx serve .
```
